# Agent skills

Официальные Angular agent skills лежат в репозитории, в `.claude/skills/`, и закоммичены вместе с кодом.

| Skill               | Что даёт                                                                                                                                                                                                                                                                          |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `angular-developer` | Генерация кода и архитектурные рекомендации: signals, `linkedSignal`, `resource` / `httpResource`, формы (в т.ч. Signal Forms), DI, роутинг, SSR, ARIA, анимации, стили, тестирование, Angular CLI. Плюс ~40 файлов в `references/`, которые скил подтягивает по мере надобности. |
| `angular-new-app`   | Создание нового Angular-приложения через CLI с правильными флагами. В монорепо почти не нужен, но идёт в одном наборе с апстримом.                                                                                                                                                |

Источник — [angular/skills](https://github.com/angular/skills) (выкладка из `angular/angular`, каталог `skills/dev-skills/`), лицензия MIT.

## Почему в репозитории, а не глобально

Скилы — это часть инструкций, по которым агент пишет наш код, поэтому они версионируются вместе с кодом:

- одинаково видны в облачных сессиях Claude Code и при локальном запуске — ставить ничего не надо, достаточно `git clone`;
- в ревью видно, какая версия скилов действовала, и обновление приходит отдельным диффом;
- нет расхождения между разработчиками, у каждого из которых свой глобальный набор.

`.claude/` целиком был в `.gitignore` (там локальное состояние агента). Под контролем версий только `.claude/skills/`:

```gitignore
.claude/*
!.claude/skills/
```

Prettier эти файлы не форматирует (`.prettierignore`) — они должны оставаться байт-в-байт апстримными, иначе дифф при обновлении показывает переформатирование вместо реальных изменений.

## Обновление

```bash
pnpm skills:update
```

Команда перекачивает скилы из апстрима и обновляет `skills-lock.json` (источник и хеши). Дифф после неё — это ровно то, что поменялось у Angular; его стоит просмотреть, прежде чем коммитить.

Поставить набор заново (например, если каталог удалили):

```bash
npx -y skills@latest add https://github.com/angular/skills --skill '*' --agent claude-code --copy -y
```

Флаг `--copy` обязателен: по умолчанию `skills` кладёт симлинки на каталог вне репозитория, а такие ссылки не переживают ни git, ни облачную сессию.
